# site/ — public report

`index.html` is generated by the pipeline, not edited by hand:

```powershell
.venv\Scripts\python.exe -m gtaf report-public --out site/index.html
```

## Publishing

GitHub's "deploy from a branch" option only accepts `/` or `/docs` as the folder, and `docs/` holds this
project's internal steering and decision documents. So the page is published by a workflow instead:

```
.github/workflows/pages.yml
```

**One setting, chosen once by the repository owner:**

1. Open https://github.com/ggotua/Propaganda-Monitoring-Dashboard/settings/pages
2. **Build and deployment → Source: GitHub Actions**
3. Save. The next push to `site/**` publishes automatically; `workflow_dispatch` runs it by hand.

The page appears at `https://ggotua.github.io/Propaganda-Monitoring-Dashboard/`.

**The repository's default branch must be `main`.** The `github-pages` environment allows deployments only
from the default branch, and this repository was created with `spec-000-kickoff` as its default: both workflow
runs failed at job setup with no step executed while `main` carried all the work. Settings → General → Default
branch → `main` fixes the deployment and also what a visitor sees first.

The file is self-contained: no external stylesheet, font, script or image, so it also opens from an email
attachment with no network.

## What must stay true in every regeneration

- The **corpus notice** at the top states that these are websites, not airtime, and quotes the measured
  site-versus-broadcast correlation.
- **Every source** appears with either a recorded editorial leaning or an explicit "unassigned" badge.
- The **limits** section names the thin classes (`supportive`), the number of outlets that carry the finding, and
  the fact that labels come from a classifier whose human agreement is stated.
- No figure in the page is computed in the renderer; all numbers come from `gtaf report-public`.
